# Commit messages

- Write commit messages in English and follow the Conventional Commits format: `<type>[optional scope]: <description>`.
- Use a lowercase type, such as `feat`, `fix`, `docs`, `refactor`, `chore`, or `test`.
- Keep the description concise and start it with a lowercase verb.

# Project skills

- Project-local skills live in `.agents/skills/`. Read and follow the relevant `SKILL.md` when working in that skill's area; do not load every skill for unrelated tasks.
- For frontend work, use `frontend-design` when creating or reshaping UI, and `tailwind-design-system` when working on Tailwind CSS v4 tokens, shared components, or responsive patterns.
- Use `web-design-guidelines` for an explicit UI, UX, or accessibility review. It fetches the current review rules when used.
- For .NET work, use `dotnet-webapi` for ASP.NET Core API changes and `csharp-expert` for other C#/.NET tasks when applicable.
- Treat these skills as task guidance; project requirements and decisions in this repository take precedence where they conflict.
